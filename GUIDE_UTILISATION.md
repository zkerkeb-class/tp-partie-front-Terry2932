# 📖 Guide d'Utilisation - Pokédex

## 🏠 Page d'Accueil (Liste des Pokémon)

### ✨ Fonctionnalités Disponibles

**1. Rechercher un Pokémon**
- Utilisez la barre de recherche en haut de page
- Tapez le nom du Pokémon (ex: "pikachu", "bulbizarre")
- Les résultats se mettent à jour en temps réel
- Valable pour les Pokémon du Pokédex et vos créations

**2. Paginer dans la Liste**
- Les Pokémon sont affichés par groupe de 20
- Utilisez les boutons "◀ Précédent" et "Suivant ▶" en bas
- L'indicateur montre la page actuelle (ex: Page 1 sur 5)
- Les boutons sont désactivés aux extrémités

**3. Ajouter un Nouveau Pokémon**
- Cliquez sur le bouton vert "➕ Ajouter un Pokémon" en haut à droite
- Vous serez redirigé vers le formulaire de création
- Votre Pokémon apparaîtra dans la section "Mes Pokémon Personnalisés"

**4. Section Pokémon Personnalisés**
- Affiche tous vos Pokémon créés en premier
- Différenciés par un badge "Personnalisé" en haut à droite
- Peuvent être cliqués pour les modifier ou supprimer

---

## 🔍 Page de Détails du Pokémon

### ✨ Fonctionnalités Disponibles

**1. Consulter les Informations Complètes**
- Cliquez sur une carte Pokémon pour voir tous ses détails
- Affichage du sprite(s)
- Identifiant (#)
- Taille et poids
- Types avec code couleur
- Capacités
- Statistiques détaillées avec barres visuelles

**2. Modifier (Pokémon Personnalisés Uniquement)**
- Cliquez sur le bouton "✏️ Modifier"
- Éditez les champs disponibles:
  - Nom
  - Type
  - Taille (en cm)
  - Poids (en hg - hectogrammes)
  - Description
  - URL de l'image
- Cliquez "✓ Enregistrer" pour valider
- Cliquez "✕ Annuler" pour abandonner

**3. Supprimer (Pokémon Personnalisés Uniquement)**
- Cliquez sur le bouton "🗑️ Supprimer"
- Une modale de confirmation s'affiche
- ⚠️ Action irréversible !
- Confirmez en cliquant "Oui, supprimer"
- Ou cliquez "Non, conserver" pour annuler

**4. Revenir à la Liste**
- Cliquez sur le bouton "◀ Retour à la liste" en haut

---

## ➕ Formulaire d'Ajout de Pokémon

### ✨ Fonctionnalités Disponibles

**1. Remplir le Formulaire**
- **Nom*** : Nom du Pokémon (obligatoire)
- **Type*** : Type du Pokémon, ex "Fire", "Water" (obligatoire)
- **Taille (cm)** : Taille en centimètres
- **Poids (hg)** : Poids en hectogrammes
- **URL de l'image** : Lien vers une image (URL complète)
- **Description** : Texte descriptif

*Champs obligatoires marqués d'un astérisque

**2. Aperçu de l'Image**
- Si vous fournissez une URL d'image valide
- Un aperçu s'affiche automatiquement
- Utile pour vérifier avant créer

**3. Créer le Pokémon**
- Remplissez les champs obligatoires
- Cliquez "✓ Créer le Pokémon"
- Vous serez redirigé vers la liste
- Votre Pokémon apparaît en section "Mes Pokémon Personnalisés"

**4. Annuler la Création**
- Cliquez "✕ Annuler" pour revenir à la liste
- Les données saisies seront perdues

---

## 🗑️ Modale de Suppression

### ⚠️ Attention !

- **Action irréversible** : Une fois supprimé, le Pokémon ne peut pas être récupéré
- **Confirmation obligatoire** : Vous devez confirmer pour supprimer
- **Deux options** :
  - "Oui, supprimer" : Supprime définitivement
  - "Non, conserver" : Annule l'opération

## 💡 Conseils d'Utilisation

### Pour Les Pokémon du Pokédex
✅ Vous pouvez voir les détails complets
✅ Vous pouvez rechercher par nom
✅ Vous pouvez naviguer entre les pages
❌ Vous ne pouvez pas modifier
❌ Vous ne pouvez pas supprimer

### Pour Vos Pokémon Personnalisés
✅ Vous pouvez modifier tous les champs
✅ Vous pouvez supprimer
✅ Vous pouvez rechercher
✅ Ils s'affichent en section dédiée
❌ Les modifications ne sont pas sauvegardées après fermeture (amélioration future)

### Recherche
🔍 Fonctionne sur :
- Tous les noms de Pokémon du Pokédex
- Tous vos Pokémon personnalisés
- Les résultats se mettent à jour instantanément
- La pagination se réinitialise à la page 1

### Navigation
🔘 Les boutons "Retour" vous ramènent toujours à la liste
🔘 Vous pouvez naviguer librement entre:
  - Liste (paginnée)
  - Détails (de n'importe quel Pokémon)
  - Ajout (de nouveau Pokémon)
